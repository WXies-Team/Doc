# API 文档

WXies Team 提供的各种实用工具 API 文档。

## 工具列表

| 工具 | 描述 | 接口地址 |
| --- | --- | --- |
| [获取 QQ 头像](/tool/qava) | 通过 QQ 号获取用户头像 | `https://api.horatio.cn/avatar/qq.php` |
| [获取 QQ 群头像](/tool/qgava) | 通过 QQ 群号获取群头像 | `https://api.horatio.cn/avatar/qqg.php` |
| [必应每日壁纸](/tool/bing) | 获取必应每日壁纸图片 | `https://api.horatio.cn/tool/bing.php` |
| [短链服务](/tool/shortener) | 创建、查询与管理短链，支持自定义代码、过期与覆盖 | `https://tio.fyi/api.php` |

## 使用说明

所有工具均通过 API 接口调用，接口地址、请求方法与返回格式见各接口页的「接口信息」表。

### 调用方式

- **请求方法**：读操作用 `GET`；短链服务的写操作用 `POST`（携带 JSON body）
- **返回格式**：图片类接口返回 `302` 重定向到图片地址，其余返回 `JSON`（UTF-8）
- **鉴权方式**：头像与壁纸接口无需鉴权，短链服务需 API 密钥
- **响应时间**：通常 < 500ms

### 错误处理

| HTTP 状态码 | 说明 |
| --- | --- |
| `302` | 成功，重定向到图片地址 |
| `200` | 成功返回 JSON；短链服务的业务错误也返回 `200` + `"success": false` |
| `400` | 请求参数错误，返回 JSON 错误体 |
| `403` | 命中站点防火墙（WAF），返回 HTML 拦截页 |
| `410` | 短链已过期或访问次数达上限 |
| `502` | 服务器内部错误 |

各接口的具体错误文案与返回体见对应页面的「错误处理」表。
